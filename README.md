# StockFácil

Sistema de control de inventario que apoya la gestión de los productos
disponibles en el almacén de TecnoMarket.

## Propósito
Permitir registrar productos, validar sus datos, actualizar el stock y
consultar la disponibilidad de cada producto.

## Módulos principales
- Registro de productos
- Validación de productos
- Actualización de stock
- Consulta de disponibilidad

## Estructura del proyecto
- Controllers: coordina las solicitudes relacionadas con productos.
- Models: representa las entidades del sistema.
- Services: contiene las reglas y la lógica del negocio.
- Data: gestiona el acceso a los datos.
- Views: representa la interacción con el usuario.

## Control de versiones
El proyecto utiliza Git y GitHub. Las mejoras se desarrollan en ramas
independientes y se integran a main mediante merge o Pull Request.
